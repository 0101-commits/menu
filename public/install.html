맛핀 앱 설치 점검

이 휴대폰의 브라우저가 맛핀을 앱으로 설치할 수 있는지 직접 확인합니다. 결과는 몇 초 안에 채워집니다.

확인하는 중…

브라우저의 설치 신호를 기다립니다. 화면을 한 번 눌러 주세요.

맛핀 열기

    예전에 받아 둔 맛핀 파일(서비스워커·캐시)을 지우고 새로 받습니다. 방문기록·화면 설정은 지우지 않습니다.

    그래도 설치 메뉴가 안 보이면

    1. 카카오톡에서 연 화면이면 오른쪽 아래 ⋮ › 다른 브라우저로 열기로 나가세요. 카톡 안 화면에는 설치 메뉴가 없습니다.
    2. 삼성 인터넷: 주소창 오른쪽의 ⤓ 내려받기 모양 아이콘, 또는 아래 ≡ › 현재 페이지 추가 › 홈 화면.
    3. 크롬: 오른쪽 위 ⋮ › 앱 설치. 홈 화면에 추가만 보이면 그것을 눌러도 창에서 설치를 고를 수 있습니다.
    4. 이미 설치돼 있으면 메뉴에 설치 대신 열기가 나옵니다. 앱 목록에서 맛핀을 찾아 보세요.
