맛핀 지도 켜기

카카오 지도는 콘솔에 등록한 주소에서만 내려옵니다. 이 페이지가 지금 열려 있는 주소로 직접 시험해 보고, 안 되면 등록할 것을 그대로 복사해 드립니다.

확인하는 중…

이 주소로 지도 SDK 를 실제로 불러 봅니다.

맛핀 열어 보기

  1. 카카오 개발자 콘솔에서 내 앱 열기

    로그인한 뒤 목록에서 맛핀이 쓰는 앱을 고릅니다.

    내 애플리케이션 열기 ↗

  2. 왼쪽 메뉴에서 앱 설정 › 플랫폼 → Web 의 사이트 도메인 등록

    아래 두 줄을 등록합니다. 위는 배포 주소, 아래는 개발용입니다. 경로(/menu)는 빼고 주소만 넣습니다.

    https://0101-commits.github.io
    http://localhost:5173
    http://localhost:5173

    지금 이 페이지 주소가 위와 다르면 지금 주소를 등록해야 합니다. 아래 버튼이 현재 주소를 그대로 복사합니다.

  3. 제품 설정 › 카카오맵 이 켜져 있는지 확인

    꺼져 있으면 도메인을 등록해도 지도가 내려오지 않습니다.

  4. 위로 올라가 다시 확인을 누릅니다

    초록불이 되면 끝입니다. 반영이 늦을 수 있으니 안 되면 30초쯤 뒤 한 번 더 눌러 보세요.

지도 말고 나머지 — 카카오 평점까지 채우려면

지금은 카드의 카카오 칸이 “미매칭”으로 보입니다. 가게마다 카카오 장소 ID 를 붙여야 카카오 평점·영업시간·메뉴·가격이 들어옵니다. 이건 브라우저가 아니라 내 컴퓨터에서 한 번 돌리는 작업입니다. 무료이고 카드 등록도 필요 없습니다.

  1. 같은 앱의 앱 설정 › 앱 키 에서 REST API 키를 복사합니다. (지도용 JS 키와 다른 값입니다)
  2. 프로젝트 폴더의 .env 에 아래 줄을 넣고 값을 채웁니다.
KAKAO_REST_KEY=
  1. 터미널에서 npm run match → npm run ratings → npm run build:data
  2. GitHub 저장소 Settings › Secrets and variables › Actions 에도 같은 이름으로 넣으면 주간 자동 갱신이 이어집니다.

자세한 설명은 저장소의 docs/keys.html 에 있습니다.

등록해도 지도가 안 뜨면 브라우저 캐시를 비우고(강력 새로고침) 다시 확인해 보세요. 이 페이지는 맛핀과 같은 주소에서 열려야 의미가 있습니다 — 파일로 열면 검사할 주소가 달라집니다.
