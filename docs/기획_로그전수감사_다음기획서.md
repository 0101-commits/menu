## 3. 충돌·오래된 내용 (다음 기획서가 반드시 알아야 할 것)

세 문서를 시간순으로 겹쳐 읽으면 **뒤 문서가 앞 문서를 덮은 지점**과 **구현이 문서를 덮은 지점**이 있다. 다음 기획서는 아래를 최신값으로 취급해야 한다.

**A. 구글 보관 정책 — 문서 3개가 서로 다른 말을 한다. 최종은 "영구 보관".**
- `개편안_모바일`(09-19) G5: "(B) 현행 유지(120일) + 수집일 표기"를 현실적이라 권고.
- `기획_구글평점확보`(09-19) §3·§5: 위를 뒤집어 **"30일 TTL, 본 것만"**(경로 A)을 권고, 전량 시드 폐기 주장.
- `기획_지도UX`(09-21) §7: 위 둘을 다시 뒤집어 **"TTL 없음(영구) + `at` + 롤링 갱신 + 전량 시드 O"**로 사용자 최종 결정.
- **구현된 진실**: `worker/index.js` L119 — `g:` 키 TTL 없음. 시드 3,604건 KV 상주.
- → **오래됨 표시**: `기획_구글평점확보.md` 의 §3.2·§5-D1 "30일 TTL" 권고, `개편안_모바일.md` 의 "120일 크론" 서술은 **모두 폐기된 안**이다. 다음 기획서에서 보관정책을 다시 논할 땐 "영구 보관 + 롤링"에서 출발할 것. **단, 약관 리스크는 미해결로 살아 있다(§4-③).**

**B. 목록 리셋 기준 — "내용 서명"은 폐기, "resetKey"가 진실.**
- `기획_지도UX` P1-1 은 "내용 서명이 같으면 유지"를 권고했으나, 지도를 40px 만 밀어도 가장자리 가게가 들고 나 서명이 바뀌는 문제로 **구현에서 `resetKey`(사용자가 바꾼 정렬/필터 조건)로 변경**됐다. `listSignature` 는 살아있지만 용도가 "이 지역에서 다시 찾기 버튼 표시 판단"으로 바뀌었다(`App.tsx` L508, `PlaceList.tsx` L65·L71).
- → 다음 기획서가 목록 리셋/스크롤 보존을 건드린다면 **서명 기반이 아니라 `resetKey` 기반**이라는 현실에서 출발할 것.

**C. 지도 위 팝업 — 모바일에선 이미 없다.**
- `개편안_모바일` P0-1 은 팝업을 "제자리로 옮기는" 데 반나절을 썼는데, 바로 다음 회차 `기획_지도UX` P0-2 가 **팝업 자체를 폐지**하고 마커 라벨+선택 카드로 대체했다(`centerForPopup` 제거). 데스크톱만 팝업 유지.
- → `개편안_모바일` 부록 A2 의 "CustomOverlay anchor 버그" 무용담은 **모바일에선 이미 사문화**됐다. 데스크톱 팝업 코드에만 유효.

**D. 갱신 메커니즘 — 크론이 아니라 "본 순간".**
- 세 문서·README 초안이 모두 "매일 03:30 KST cron"을 전제했으나, Cloudflare 무료 5개 cron 한도 초과(`code:10072`)로 **거절**됐다. 구현은 `/google?ids=` 응답 경로에서 `at` 이 오래된 것을 `ctx.waitUntil(refreshSome(...))` 로 최대 5건 뒤에서 갱신(`worker/index.js` L174, `VIEW_REFRESH_MAX`). `scheduled` 핸들러는 코드에 남았지만 트리거는 없다(L184).
- → **README 의 "#### 구글 평점을 채우고 굴리는 법" 3번 항목("Cron Trigger 가 매일 03:30")은 사실과 다르다** — 트리거가 안 걸려 있다. README 다른 곳(온디맨드+cron 이 한도 공유)도 현재는 "보는 순간 갱신"만 동작. **다음 기획서가 README 정정을 포함하거나 별도 이슈로 남길 것.**
