맛핀 (Matpin) API 키 발급 가이드

지도와 평점 기능을 켜는 데 필요한 키 3종을 순서대로 발급한다. 개발 지식이 없어도 그대로 따라 하면 된다.

한눈에 보기

키왜 필요한가비용카드 필요없으면
카카오 JS 앱키 지도 타일 표시 (도메인 등록만 하면 됨, 키 자체는 이미 있음) 무료 아니오 지도가 안 뜬다 (지금 상태)
카카오 REST API 키 가게마다 카카오 장소 ID 매칭 → 카카오 평점 수집 무료 (일 100,000건) 아니오 카카오 평점 칸이 비어 있다
구글 Places API 키 구글 평점 표시 개인 사용 범위 내 무료 예 구글 평점 칸이 "—", 구글 버튼은 지도 링크로만 동작 (앱은 정상)

1단계 — 카카오 JS 앱키 도메인 등록 필수

지도용 키 489abbeb60a4ef5ff58d960dcaeecb4e 는 이미 index.html 에 들어 있다. 카카오맵 SDK는 등록된 도메인에서만 지도를 그리기 때문에, 도메인만 등록하면 된다.

  1. developers.kakao.com 로그인 → 내 애플리케이션 → 이 프로젝트의 앱 선택
  2. 앱 설정 > 플랫폼 > Web 에서 사이트 도메인 등록 클릭
  3. 아래 두 도메인을 각각 등록한다. 
    https://0101-commits.github.io
http://localhost:5173
    첫 번째는 배포 주소, 두 번째는 로컬 개발 서버(Vite 기본 포트) 주소다.
  4. 제품 설정 > 카카오맵 에서 활성화 상태인지 확인
완료 조건두 도메인이 목록에 모두 보이면 끝. 카드 등록, 결제 없음.

2단계 — 카카오 REST API 키 필수

1단계와 같은 앱에서 나오는 다른 키다. 지도용 JS 앱키와 절대 혼동하지 말 것.

  1. 같은 앱에서 앱 설정 > 앱 키 로 이동
  2. REST API 키 값을 복사
  3. .env 의 KAKAO_REST_KEY 에 붙여넣는다
  4. GitHub 저장소에도 등록: 0101-commits/menu 저장소 → Settings > Secrets and variables > Actions > New repository secret → 이름 KAKAO_REST_KEY, 값은 같은 키

이 키는 scripts/match.mjs 가 4,084개 가게의 카카오 장소 ID를 찾을 때 쓴다. 하루 100,000건까지 무료라 한 번 전체 매칭에는 넉넉하다.

3단계 — 구글 Places API 키 선택

카드 등록이 반드시 필요하다 구글 지도 플랫폼은 무료 할당량 안에서만 써도 결제 계정(카드) 연결을 요구한다. 카드를 등록하지 않으면 이 단계는 건너뛰어도 된다 — 앱은 네이버·카카오 두 소스만으로 정상 동작하고, 카드의 구글 칸은 — 로 남으며 구글 버튼은 지금처럼 지도 링크로만 작동한다. 아무것도 깨지지 않는다.

카드를 등록하기로 했다면, 아래 사용량은 실제로 개인 사용 범위에서 무료 등급 안에 머문다.

API용도단가월 무료 할당량실제 사용량
Text Search Pro매칭 (fieldMask: places.id,places.location,places.displayName)$32 / 1,000건5,000건4,084곳 1회 매칭 → 무료
Place Details Enterprise평점 (fieldMask: rating,userRatingCount,priceLevel,regularOpeningHours)$20 / 1,000건1,000건실제로 열어 본 가게만, 30일 캐시 → 무료 범위
fieldMask에 reviews 를 넣지 말 것넣는 순간 Enterprise + Atmosphere 등급($25/1,000건 추가)으로 올라간다.

구글 정책상 지켜야 할 것 두 가지 — 이 프로젝트는 이미 반영돼 있다: 평점 등 데이터는 30일 넘게 저장할 수 없고, 구글 데이터를 보여주는 화면에는 "Google" 표기가 있어야 한다.

  1. console.cloud.google.com → 새 프로젝트 만들기
  2. 결제 계정 연결 (카드 등록)
  3. API 및 서비스 > 라이브러리 에서 "Places API (New)" 검색 → 사용 설정
  4. API 및 서비스 > 사용자 인증 정보 > API 키 만들기
  5. 만든 키를 반드시 제한한다.
    • API 제한: Places API (New) 만 허용
    • 애플리케이션 제한: 없음 — 서버/CI(GitHub Actions)에서 호출하므로 HTTP 리퍼러 제한을 걸면 안 된다
  6. 예산 알림(Budget alert)을 $1 로 설정해 두는 것을 권장한다

발급한 키는 .env 의 GOOGLE_PLACES_KEY 와, GitHub 저장소 Secret GOOGLE_PLACES_KEY 에 동일하게 등록한다 (등록 방법은 2단계와 동일한 화면).

4단계 — .env 채우기 + GitHub Secrets 등록

참고로 NAVER_COOKIE 는 즐겨찾기 동기화용 기존 키다. 이미 설정돼 있다면 그대로 두면 된다.

cp .env.example .env

.env 파일을 열어 아래 세 값을 채운다.

NAVER_COOKIE=...       # 이미 있다면 그대로 유지
KAKAO_REST_KEY=...     # 2단계에서 발급
GOOGLE_PLACES_KEY=...  # 3단계에서 발급 (선택, 안 하면 빈 값)

GitHub Actions에서도 같은 키가 필요하다. 저장소 0101-commits/menu → Settings > Secrets and variables > Actions 에서 KAKAO_REST_KEY, GOOGLE_PLACES_KEY (등록했다면) 를 각각 New repository secret 으로 추가한다.

5단계 — 실행 순서

npm run match       # 카카오/구글 장소 ID 매칭 (한 번)
npm run ratings      # 평점 수집 (네이버는 키 없이도 됨)
npm run build:data   # public/data/*.json 생성 + 게이트 검사

7단계 — 자주 막히는 곳

  • 지도 타일이 안 보임 — 1단계 도메인 미등록. 현재 접속 중인 주소(포트 포함)가 카카오 콘솔에 정확히 등록됐는지 확인.
  • KAKAO_AUTH 오류 — REST API 키 자리에 JS 앱키를 넣은 경우. 2단계에서 앱 설정 > 앱 키 > REST API 키 값인지 다시 확인.
  • 구글 REQUEST_DENIED — 결제 계정 미연결 또는 "Places API (New)" 미활성화. 3단계 2번, 3번을 다시 확인.
  • GitHub Actions에서만 실패 — 로컬 .env 에는 값이 있지만 저장소 Secret 등록을 안 한 경우. 4단계의 Secrets 등록을 확인.
